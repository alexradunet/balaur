Use BuildContext

Use this guide when code must find a theme, router, media value, or other tree service.

Definition

A BuildContext is a restricted interface to an Element.

It identifies one mounted location in the element tree.

It does not contain global application state.

Ancestor lookup

Theme.of(context)
MediaQuery.of(context)
Navigator.of(context)
GoRouter.of(context)
context.go('/settings')

These operations start at the context location.

They search the ancestor chain for the required service.

Rules

  • Use the context below the provider that you must find.
  • Do not store a context for later general use.
  • Check context.mounted after an asynchronous gap.
  • Use a Builder when you need a context below a new widget.
  • Remember that each mounted widget has a different context.

Asynchronous use

await saveSettings();

if (!context.mounted) return;
context.go('/chat');

Diagnostic question

Ask this question when an ancestor lookup fails:

Is this context below the provider that I want to find?
