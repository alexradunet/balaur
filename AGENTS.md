# Writing standard

Use ASD-STE100 Simplified Technical English (STE) for all natural-language output.

Apply this rule to:

- User conversations.
- Documentation and lessons.
- Plans, reports, and explanations.
- User-facing messages and interface text.
- Code comments when you add or change them.

Use these STE controls:

- Use approved STE words with their approved meanings when possible.
- Use project terms as technical names or technical verbs when they are necessary.
- Use the same term for the same item or action.
- Use active voice.
- Give one instruction in each sentence.
- Make each procedural sentence 20 words or fewer.
- Make each descriptive sentence 25 words or fewer.
- Keep each paragraph to six sentences or fewer.
- Use simple verb tenses.
- Use articles where they are necessary.
- Use vertical lists for complex information.
- Define each abbreviation at its first occurrence.

Keep source code, commands, paths, identifiers, API names, error text, and direct quotations unchanged.

Before each response or prose change, check the text for STE compliance. Revise the text before delivery.
