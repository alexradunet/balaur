# Triage labels

The engineering skills use five canonical triage roles.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | The reporter must provide more information. |
| `ready-for-agent` | `ready-for-agent` | An agent can complete the issue without guidance. |
| `ready-for-human` | `ready-for-human` | A human must complete the issue. |
| `wontfix` | `wontfix` | The project will not complete the issue. |

Use the GitHub label when a skill names its canonical role.
